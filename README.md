# ТехноМаркет — интернет-магазин на React и Go

Учебный проект по дисциплине «Фронтенд и бэкенд разработка».
Интернет-магазин гаджетов: фронтенд на React, бэкенд на Go.

**Сайт на GitHub Pages:** https://aive322.github.io/kr1-html-css-shop/

## Технологии

- React 19, React Router, Vite
- Bootstrap 5, Bootstrap Icons, шрифт Manrope (подключены локально через npm)
- Go (стандартная библиотека `net/http`)
- Git, GitHub, GitHub Pages

```text

├── scripts/sync-data.mjs  – копирует products.json из backend в public/ перед сборкой
├── public/                – фото товаров, favicon (логотип), robots.txt, 404.html для GitHub Pages
└── src/
    ├── main.jsx, App.jsx  – точка входа и маршруты
    ├── components/        – логотип, шапка, подвал, поиск, карточка товара, кнопка «В корзину», счётчик количества, Reveal и CountUp (анимации)…
    ├── pages/             – Home, Catalog, Product, Cart, Order (оформление), Account, About, Contacts, Favorites, NotFound
    ├── context/           – товары с сервера, избранное, корзина, личный кабинет, тема, уведомления
    ├── data/company.js    – контакты магазина, отделы, стоимость доставки
    ├── hooks/             – usePageMeta (title и description для SEO), useInView (появление при прокрутке)
    ├── utils/             – price.js (цена, скидка, статус товара), storage.js (безопасная работа с localStorage)
    └── styles/app.css     – собственная тема поверх Bootstrap
backend/                   – сервер на Go
├── main.go                – GET /api/products, раздача собранного сайта, gzip
├── main_test.go           – тесты (go test)
└── data/products.json     – данные 18 товаров
docs/                      – собранный сайт для GitHub Pages
lighthouse/                – отчёт Lighthouse (Accessibility, Best Practices, SEO)
```

## Страницы

- **Шапка:** логотип, меню, поиск по каталогу (кнопка или Ctrl+K, результаты сразу при вводе), переключатель светлой и тёмной темы, избранное, личный кабинет, корзина со счётчиком.
- **Подвал:** логотип, подписка на скидки, разделы «Покупателям» и «Компания», контакты с иконками и временем работы, соцсети, способы оплаты.
- **Главная:** промо-блок, статистика каталога, популярные товары, скидки недели, преимущества, отзывы.
- **Каталог:** поиск, подборки (хиты, новинки, скидки), цена до, «только в наличии», сортировка.
- **Товар:** фото, цена и скидка, наличие, выбор количества и «В корзину», характеристики, сравнение с похожими, отзывы со шкалой оценок и форма отзыва (для вошедших), похожие товары.
- **Корзина:** количество «− 1 +», удаление, очистка, скидка, бесплатная доставка от 5 000 ₽ (с полоской прогресса), «С этим покупают».
- **Оформление заказа:** получатель, курьер (адрес) или самовывоз, оплата при получении (картой, СБП, наличными), комментарий; проверка полей; после отправки — номер заказа.
- **Личный кабинет:** вход и регистрация (пароль хранится только в виде хеша SHA-256), вкладки «Мои заказы», «Избранное», «Мои отзывы», «Профиль» (имя, телефон, адрес доставки), удаление аккаунта с подтверждением. Данные подставляются в форму заказа.
- **О компании:** история, цифры, принципы, этапы развития, команда.
- **Контакты:** телефоны и почта, магазин и пункт самовывоза (режим работы, как добраться, схема проезда), отделы, доставка и оплата, форма обратной связи, частые вопросы, политика конфиденциальности.
- **Избранное:** товары, отмеченные сердечком (хранятся в `localStorage`).
- **404** для несуществующих адресов.

## Анимации

- **Переход между страницами:** новая страница плавно проявляется.
- **Появление при прокрутке:** карточки, заголовки секций, отзывы и блоки появляются снизу по очереди (компонент `Reveal` на `IntersectionObserver`).
- **Главный экран:** текст появляется по строкам, фото товаров «парят», фон медленно переливается.
- **Статистика:** числа «набегают» от 0, когда блок появляется на экране (компонент `CountUp`).
- **Мелкие анимации:** подъём кнопок и карточек при наведении, сердечко «Избранное» подпрыгивает, счётчик избранного «пульсирует», полоски рейтинга заполняются, поля с ошибкой в форме «трясутся», меню на телефоне выезжает, у шапки появляется тень при прокрутке.
- **Загрузка:** вместо пустого места — мерцающие заготовки карточек (skeleton).
- **Кнопка «Наверх»** появляется после прокрутки страницы.
- **Смена темы:** новая тема раскрывается кругом от кнопки (View Transitions API); в браузерах без этой технологии цвета меняются плавно. Тема запоминается и ставится до загрузки страницы, без «мигания».
- **Уведомления** (toast) внизу экрана: товар в корзине, вход, сохранение профиля, подписка.
- **Схема проезда** в контактах: маршрут от метро «бежит», метка покачивается.

Если в системе включено «Уменьшить движение» (`prefers-reduced-motion`), анимации отключаются, а содержимое сразу видно.

## Как запустить

Нужны Node.js 20.19+ (или 22.12+) и Go 1.22+.

Один сервер — сайт и API с одного адреса:

```bash
cd frontend
npm install
npm run build
cd ../backend
go run .
```

Открыть http://localhost:8080. Список товаров: http://localhost:8080/api/products.

Режим разработки (два терминала):

```bash
cd backend && go run .        # API на :8080
cd frontend && npm run dev    # сайт на http://localhost:5173
```

Vite перенаправляет запросы `/api` на Go-сервер.

Тесты сервера: `cd backend && go test ./...`

## API

`GET /api/products` → `200 OK`, `application/json`, массив товаров:

```json
[{ "id": 3, "slug": "power-bank", "title": "Power Bank 20000", "price": 2000, "oldPrice": 2500,
   "discountPercent": 20, "badge": "−20%", "isAvailable": true, "rating": 4.8, "reviewsCount": 4,
   "specs": [["Ёмкость", "20 000 мА·ч"]], "reviews": [{ "author": "Николай Ф.", "rating": 5, "text": "…" }] }]
```

Другие методы получают `405 Method Not Allowed`. Ответы сжимаются gzip, файлы сборки из `/assets/` кешируются браузером.

## GitHub Pages

Сайт публикуется из папки `docs/` ветки `main` (Settings → Pages → Branch: `main`, папка `/docs`).
Сервер на Go на GitHub Pages работать не может, поэтому эта сборка берёт товары из файла `products.json`.
Файл `docs/404.html` открывает нужную страницу React по прямой ссылке (например, `/kr1-html-css-shop/catalog`).

Пересобрать: `cd frontend && npm run build:pages`.

## Проверка

- Lighthouse (через Go-сервер, все страницы, Mobile и Desktop): Accessibility 100, SEO 100, Best Practices 100. Отчёт главной: `lighthouse/react-report.html`, скриншот: `lighthouse/react-report.png`.
- Светлая и тёмная темы проверены axe-core на всех страницах (телефон и компьютер): нарушений, в том числе по контрасту, нет.
- Адаптивность: страницы на ширинах 360, 430, 768, 1024 и 1440 px — горизонтальной прокрутки нет, ошибок в консоли нет.
- Проверено, что анимации не мешают доступности: после появления все блоки видимы, при «Уменьшить движение» всё показывается сразу.
- Проверены поиск, фильтры и сортировка, избранное, корзина и оформление заказа, регистрация, вход, неверный пароль, профиль и удаление аккаунта, отзывы, смена темы, валидация форм (ошибки под полями, фокус на первое поле с ошибкой), меню на телефоне, открытие страниц по прямой ссылке.
