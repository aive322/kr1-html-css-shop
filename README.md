# Учебный frontend-проект 

## Описание 

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг. 

## Структура проекта 

- `index.html` — главная страница; 
- `catalog.html` — каталог товаров; 
- `contacts.html` — контактная информация;
- `product.html` — карточка товара: таблица характеристик, отзывы;
- `order.html` — отдельная страница оформления заявки;
- `css/style.css` — файл стилей; 
- `js/main.js` — файл JavaScript; 
- `images/` — папка для изображений; 
- `README.md` — описание проекта; 
- `.gitignore` — список файлов, исключённых из Git.
- `sitemap.xml` — простая карта сайта;

## CSS-архитектура 

В проекте используются: 

- CSS-переменные в `:root`; 
- единая шкала отступов; 
- переменные для цветов и скруглений; 
- состояния `:hover`, `:focus-visible`, `:disabled`; 
- визуальная подсветка ошибочных полей через `aria-invalid`; 
- структурированный файл `css/style.css`.

## Использование Flexbox и Grid 

В проекте используются: 

- Flexbox для основного меню; 
- Flexbox для внутренней структуры карточек товаров; 
- CSS Grid для сетки карточек; 
- CSS Grid для страницы каталога с фильтрами и списком товаров.

## БЭМ-структура проекта 

В проекте используются следующие БЭМ-блоки: 

## БЭМ-блоки проекта

- `site-header` — шапка сайта (sticky);
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `section` — универсальный раздел;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара (с бейджами и модификаторами);
- `product-detail` — карточка товара на отдельной странице;
- `product-table` — таблица характеристик;
- `reviews-list` / `review` — блок отзывов;
- `faq-item` — блок частых вопросов (на `<details>`/`<summary>`);
- `catalog-layout` — макет страницы каталога;
- `catalog-filters` — фильтры каталога (sticky);
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки (в модалке, на `order.html` и `contacts.html`);
- `button` — кнопка с модификаторами `--primary` / `--secondary`;
- `success-message` — сообщение об успешной отправке;
- `site-footer` — подвал;
- `scroll-top` — фиксированная кнопка «Наверх».

## Самостоятельные доработки

1. **Расширенный каталог** — 6 товаров вместо 3.
2. **Бейджи на карточках** — «Хит», «Новинка», «Скидка» через `position: absolute` и модификаторы БЭМ.
3. **Sticky-шапка и sticky-фильтр** каталога.
4. **Фиксированная кнопка «Наверх»** с плавным появлением по скроллу.
5. **Отдельная страница `product.html`** с таблицей характеристик и блоком отзывов.
6. **Блок FAQ** на `<details>`/`<summary>` — доступный интерактив без JS.
7. **Отдельная страница `order.html`** — форма заявки вне модального окна.
8. **Форма обратной связи на `contacts.html`** с собственной валидацией.
9. **Улучшенная доступность**: `aria-describedby`, `aria-invalid`, `role="status"`, `aria-label`, видимый фокус, подсказки под полями.
10. **Адаптивная сетка** (базовая): 3 -> 2 -> 1 колонка.
