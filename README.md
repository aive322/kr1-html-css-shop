# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` – главная страница;
- `catalog.html` – каталог товаров;
- `product.html`, `product-2.html` … `product-9.html` – страницы товаров (у каждого товара своя страница);
- `order.html` – страница оформления заявки;
- `contacts.html` – контактная информация;
- `css/style.css` – файл стилей;
- `js/main.js` – JavaScript модального окна на главной странице;
- `js/order-form.js` – доступная валидация формы на странице заявки;
- `js/card-states.js` – переключатель «В избранное» (состояние «выбрано» у карточки);
- `js/image-fallback.js` – подстановка фотографий товаров из `images/photos/` вместо иллюстраций;
- `images/` – изображения товаров: SVG-иллюстрации (запасной вариант) и фотографии в `images/photos/`;
- `.gitignore` – список файлов, исключённых из Git;
- `README.md` – описание проекта.

## Используемые технологии

## Реализованные элементы интерфейса

- карточки товаров на главной странице и в каталоге (Grid-сетка);
- отдельная страница товара с изображением, описанием, ценой и бейджем;
- таблица характеристик товара (`caption`, `thead`, `tbody`, `th`, `td`);
- форма фильтров в каталоге (категории, диапазон цены);
- отдельная страница оформления заявки с валидацией средствами браузера;
- модальное окно с формой заявки на главной странице;
- поля формы: имя, e-mail, телефон, дата/товар, комментарий, согласие;
- базовая HTML-валидация и базовая JS-обработка формы (только для модального окна);
- сообщение об успешной отправке;
- кнопка «Наверх» с фиксированным позиционированием.

## CSS-архитектура

В проекте используются:
- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`;
- базовое БЭМ-именование классов (например, `product-card__button`, `product-detail__badge`, `site-nav__list`).

## Использование Flexbox и Grid

В проекте используются:
- Flexbox для основного меню (`site-nav__list`);
- Flexbox для внутренней структуры карточек товаров (кнопка прижата к низу);
- Flexbox для карточки товара на отдельной странице;
- CSS Grid для сетки карточек (`products-grid`);
- CSS Grid для страницы каталога с именованными областями (`grid-template-areas: "filters products"`).

## Позиционирование

- `position: relative` — контейнер изображения на странице товара;
- `position: absolute` — бейдж «Хит» поверх изображения;
- `position: sticky` — блок фильтров в каталоге;
- `position: fixed` — кнопка «Наверх»;
- `z-index` — используется для бейджа и кнопки «Наверх».

## Навигация и многостраничная структура

- единое меню на всех страницах (`index.html`, `catalog.html`, `product.html`, `order.html`, `contacts.html`);
- переходы между всеми основными страницами, включая страницу товара и страницу заявки;
- якорные ссылки на главной странице (`#advantages`, `#popular`, `#contacts`);
- хлебные крошки на внутренних страницах;
- плавная прокрутка к якорям (`scroll-behavior: smooth`);
- подсветка раздела, к которому выполнен переход (`:target`);
- уникальные `title` и `meta description` для каждой страницы.
## БЭМ-структура проекта

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара (с модификаторами `--featured`, `--discount`);
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки (переиспользуется в модалке и на `order.html`);
- `button` — кнопка (модификаторы `--primary`, `--secondary`);
- `site-footer` — подвал сайта.

## Как посмотреть проект

1. Открыть опубликованную версию на GitHub Pages (ссылка ниже).
2. Либо скачать репозиторий и открыть файл `index.html` в браузере.
3. Перейти по меню на страницы «Каталог», «Контакты», «Оформить заявку».
4. На главной странице нажать «Заказать» у любого товара — откроется модальное окно с формой.
5. Прокрутить страницу вниз — кнопка «Наверх» остаётся в углу экрана, а на странице каталога панель фильтров «прилипает» к верху окна.

## Самостоятельные доработки

К базовым требованиям методички добавлены следующие доработки.

Уже реализованы ранее:

- фиксированная кнопка «Наверх» (`position: fixed`, блок `back-to-top`) на всех страницах;
- закреплённое верхнее меню с разделами «Главная», «Каталог» и др. (`position: sticky`, блок `site-header`), якоря и фильтр каталога учитывают его высоту;
- sticky-фильтр каталога (`position: sticky`, блок `catalog-filters`), прилипает под закреплённым меню;
- варианты карточек через БЭМ-модификаторы: `product-card--featured` (хит), `product-card--new` (новинка), `product-card--discount` (скидка со старой ценой и меткой «−20%»), `product-card--sold-out` (нет в наличии), `product-card--selected` (выбрано); метка карточки – элемент `product-card__badge` с модификаторами, старая цена – `product-card__old-price`;
- дополнительные состояния кнопок и карточек: `:hover`, `:active` (нажатие), `:focus-visible`, `:focus-within` у карточки, `:disabled` / `button--disabled`, переключатель `button--toggle` с `aria-pressed` и выбранная карточка `product-card--selected`, плавные переходы (`transition`);

Добавлены дополнительно:

- реальные названия товаров вместо «Товар 1–9», изображения (фотографии) и отдельная страница для каждого товара со своими характеристиками, сравнением и отзывами;
- блок отзывов на страницах товаров (4–6 отзывов на товар), средняя оценка и распределение оценок (блок `review-card`, модификатор `review-card--critical`, адаптивная сетка);
- блок часто задаваемых вопросов на `contacts.html` (блок `faq`, нативные `<details>`/`<summary>`);
- расширенная таблица сравнения товаров на `product.html` (блок `compare-table`, `scope` у заголовков, прокрутка на узких экранах);
- улучшенная доступность формы на `order.html`: отметка обязательных полей, `aria-describedby`, сообщения об ошибках рядом с полем, общий список ошибок с `role="alert"`, перевод фокуса на первое неверное поле, сообщение об успехе с `role="status"` (скрипт `js/order-form.js`).
